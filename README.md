# N2星海远征｜日语二级研修场

一个以开放世界冒险机制为灵感、但使用原创世界观与视觉的日语 N2 游戏化学习网页。

## 已接入数据

- 684 条《日语N1 N2固定搭配数据库》中的 N2 固定搭配
- 1,070 条《高频N2表达》记录
- 200 条《日本大学面试神器》语境应用记录（单独标记，不等同于 JLPT N2 题库）
- 200 条《日语听力提分神器》听力研修记录，并关联 200 个 MP3 音频
- 合计 2,154 条记录
- 阅读篇章在当前数据中没有对应记录，页面保留真实空状态

## 本地运行

```bash
npm install
npm run dev
```

构建：

```bash
npm run build
```

如需重新导入新的工作区数据库，先运行 `npm run prepare:data`；它会生成 `src/data/learning-records.json` 和 `work/data-inventory.md`。确认数据后再运行 `npm run build`。公开仓库只提交已验收的生成数据，不提交原始压缩包。

## 主要功能

- 今日远征、XP、远征阶位、星尘和连续学习
- 星海地图、区域解锁、研修秘境
- 词汇、语法、语境表达和听力研修的真实数据库卡片
- 听觉星廊：音频播放、听力要点、日语原文与完成记录
- 错题回响、1/3/7/14 复习日期、顽固回响原因记录
- 收藏、学习战报、JSON 进度导出/恢复
- localStorage 本地持久化
- GitHub Pages Actions 自动部署

## 数据边界

原始字段在 `metadata` 中保留；无法映射的内容不被静默丢弃。数据库中的“原创示例”“待核验”或其他来源标识会在详情页保留。网页不会把语境应用数据宣传成官方真题、必考内容或历年高频证据。
